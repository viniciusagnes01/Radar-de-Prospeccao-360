# Resumo Executivo

O Radar de Prospecção 360 foi desenhado para transformar prospecção em uma operação guiada por dados.

Em vez de uma lista fria, o time recebe uma lista priorizada com:

- score;
- principal dor;
- oferta sugerida;
- mensagem;
- próximo passo.

A primeira versão já roda em Next.js e pode ser publicada na Vercel.

O próximo salto de maturidade é conectar persistência com Supabase e transformar buscas em pipeline histórico.
